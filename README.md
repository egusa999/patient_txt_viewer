# 病棟テキストビューア (Ward Text Viewer)

病棟・病室ごとのサマリーテキスト（.txt）を、フォルダを選ぶだけで一覧・閲覧できるシンプルなビューアです。単一のHTMLファイルで完結する軽量PWA（Progressive Web App）として動作します。

## 特徴

- 📁 **フォルダを選ぶだけ** — 指定フォルダ内の `.txt` を自動で読み込み、ファイル冒頭の「病棟:」「病室:」を解析して病棟ごとにグループ化・部屋番号順に一覧表示
- 🔎 **一覧 → 詳細をカードフリップで表示** — 一覧の行をタップすると本文がカードめくりのアニメーションで表示され、「← 戻る」・右スワイプ・Escapeキーで一覧に戻れます
- 🗺️ **病棟マップ表示** — `病棟名_YYYYMMDD_HHMMSS.png` 形式の画像がフォルダ内にあれば、病棟見出しをタップして表示。ピンチズーム・ドラッグでのパン・ダブルタップ拡大に対応
- 🔒 **プライバシー配慮** — 一覧では患者IDの下4桁のみ表示（詳細画面では全桁表示）。データは常にローカルのフォルダから直接読み込まれ、外部サーバーへは一切送信されません
- 📲 **PWA対応** — ホーム画面に追加してアプリのように起動可能。オフラインでもアプリの外枠（UI）はキャッシュから表示されます（閲覧するテキスト自体は毎回ローカルフォルダから読み込みます）
- 💻📱 **デスクトップ・Android両対応** — Chrome/Edge等ではFile System Access APIで前回のフォルダを記憶。Android等の非対応ブラウザでは `<input type="file" webkitdirectory>` にフォールバックし、OneDriveなどクラウドアプリ内のフォルダも選択可能

## 対象テキストの形式

各 `.txt` ファイルの冒頭に以下の記載があることを前提にしています（表記ゆれにはある程度対応済み）。

```
病棟: 本館２階病棟
病室: ２０１号室

PID: 0000541056 …
年齢: 80歳（1946年5月19日生）男性
```

- PIDラベルは `PID:` / `患者ID:` / コロンなし / 文中埋め込み、いずれの表記にも対応
- 本文にPID記載が無い場合は、ファイル名（`dwh_ubie_result_XXXXXXXXXX_...`）から自動補完
- 年齢・性別は同一行・別行どちらの記載にも対応

## 使い方

### デスクトップ（Chrome / Edge）

1. `index.html` をブラウザで開く（`file://` で直接開くだけでも一覧・詳細表示は動作します）
2. 「📁 フォルダを選択」からテキストの入ったフォルダを選ぶ
3. 次回以降は自動でフォルダへの再アクセスを試みます（初回のみ許可が必要）

PWAとしてインストールし、Service Workerによるオフラインキャッシュを有効にするには、`http://` 経由で開く必要があります。同梱の `start_server.bat` を実行するとローカルサーバー（`http://localhost:8765/`）が起動します。

### Android

Chromeで開き、「📁 フォルダを選択」をタップするとシステムのフォルダ選択画面が開きます。OneDriveなど対応クラウドアプリがインストールされていれば、その中のフォルダも選択可能です。ブラウザの仕様上、フォルダの選択は起動のたびに必要です（前回の選択は記憶されません）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML/CSS/JS一体） |
| `manifest.json` | PWAマニフェスト |
| `sw.js` | Service Worker（アプリ外枠のオフラインキャッシュ） |
| `icon-*.png` | PWAアイコン（通常・maskable、192/512px） |
| `start_server.bat` | ローカルサーバー起動用（Windows） |

## 技術メモ

- File System Access API (`showDirectoryPicker`) 非対応ブラウザでは `webkitdirectory` 入力にフォールバック
- Service Workerはアプリの外枠のみキャッシュ対象（患者データ本体はキャッシュしません）
- 外部通信はGoogle Fontsの読み込みのみで、テキスト・画像データの外部送信は一切行いません

## 注意事項

このリポジトリにはアプリのコードのみを含めてください。患者データを含むテキスト・画像ファイル（サンプルフォルダ等）はコミットしないようご注意ください。
